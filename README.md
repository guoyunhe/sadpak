# Sadpak

Make simple desktop app with HTML, CSS and JavaScript. Designed for web developers.

- It is **NOT** safe, because it has node_modules from npmjs.com
- It is **NOT** fast, because it is written in JavaScript
- It saves time for those who don't want to learn C++ (Qt), Rust (Tauri) or Dart (Flutter)
- It saves RAM for those who don't like Electron apps
